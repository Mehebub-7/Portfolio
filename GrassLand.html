Grass Land

An exploration game where players cut through dense greenery with a grass cutter, gather hidden resources, and build up a base across a sprawling wilderness.

My Role

Built the grass-cutter upgrade system, resource gathering loop, and base expansion progression. Implemented a competitive multiplayer mode using Photon PUN2 where players compete head-to-head, alongside the full live-ops and monetization stack.

Technologies

  • Photon PUN2: Built real-time competitive multiplayer mode where players compete head-to-head.
  • ScriptableObjects: Stored resource, upgrade, and machine data.
  • Object Pooling: Spawned grass patches and resource instances efficiently.
  • Coroutines: Managed grass-cutter fuel depletion and base progression.
  • Appodeal: Integrated Appodeal SDK for ad mediation across multiple networks.
  • Google AdMob: Implemented banner, interstitial, and rewarded ad placements.
  • IronSource: Integrated IronSource SDK as an additional ad mediation source.
  • Unity IAP: Implemented in-app purchases for premium content and ad-removal upgrades.
  • Game Analytics: Implemented Game Analytics for player behavior tracking and funnel analysis.
  • Firebase Analytics: Integrated Firebase Analytics to capture in-game events and user metrics.
  • Firebase Crashlytics: Used Crashlytics to monitor and diagnose runtime crashes in production.
  • Firebase Firestore: Used Firestore for real-time data persistence (leaderboards, cloud save).
  • Firebase Remote Config: Tuned game parameters (difficulty, prices, events) without shipping app updates.
  • Addressables: Used Unity Addressables to load assets on-demand, reducing initial install size.
